# Roadmap

*v0.1 draft.*

## Phase 0 — Foundation (now → ~2 months)
**Goal:** a credible vision and a founding group of 25–50 members.

- [x] Founding documents v0.1 (this repository)
- [ ] Founder review of Manifesto tone and Charter numbers
- [ ] Choose final name; reserve domain and social handles
- [ ] Simple landing page with a sign-up form
- [ ] Community spaces: GitHub Discussions (proposals) + Discord (chat)
- [ ] Soft launch to personal networks; recruit the first 25 founding members
- [ ] **Ratification vote** of the Charter by founding members
- [ ] First Stewards Council election

## Phase 1 — First win (~2 → 6 months)
**Goal:** prove the model works by shipping something and earning first revenue.

- [ ] Public launch: Reddit (r/cscareerquestions, r/ExperiencedDevs, r/programming), Hacker News, LinkedIn, Facebook groups
- [ ] Run the first full proposal → vote → build cycle
- [ ] Ship the first product MVP
- [ ] Land the first client contract
- [ ] Sign the first sponsor
- [ ] Choose and form the legal entity
- [ ] Publish the first monthly treasury report

## Phase 2 — Scale the system (~6 → 12 months)
**Goal:** replace manual processes with Union-built tooling; grow to hundreds of members.

- [ ] **Union Platform** (candidate internal project): proposals, backing, weighted voting, reputation ledger, task assignment, revenue-share accounting
- [ ] Multiple concurrent product teams
- [ ] Re-skilling and mentoring program for new members
- [ ] Review and amend the Charter based on real experience

## Success metrics
| Metric | Phase 1 target |
|---|---|
| Active members | 100 |
| Shipped products | 1 |
| Members earning through the Union | 10 |
| Monthly revenue | First € / $ |
