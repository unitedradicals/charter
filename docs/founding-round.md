# Founding round

*November–December 2026. Run by the interim stewards; see [Charter §3](../CHARTER.md#3-roles).*

The Charter is a v0.1 draft. Every value marked **[placeholder]** is a starting point, and the founding members set the real values. The Founding round is how we do that, and how we choose what to build first.

## Timeline

| Dates | What |
|---|---|
| **Nov 23 – Dec 6** | **Ratification discussions.** Five threads in [Proposals](https://github.com/unitedradicals/charter/discussions/categories/proposals) (label `charter`): voting, membership, revenue split, reputation, and stewards and treasury. |
| **Dec 6** | Stewards publish the proposed **Charter v1.0** as a pull request, with every change linked to the discussion behind it. |
| **Dec 7 – Dec 13** | **Ratification vote.** Under [Charter §8](../CHARTER.md#8-ratification), the Charter takes effect when a simple majority of the first 25 founding members approve it. If there are fewer than 25 members, the vote waits. |
| **Nov 23 – Dec 13** | **Ideas call.** Post what we should build in [Ideas](https://github.com/unitedradicals/charter/discussions/categories/ideas). |
| **Dec 14 – Dec 20** | Ideas with 5 committed backers go to the **first proposal vote**. |
| **Before any code** | Everyone contributing signs the interim **Contributor Agreement** ([IP & licensing](economics/ip-and-licensing.md)). |
| **January 2027** | First **Stewards Council election**. The first project team forms. |

The 14-day membership age for voting ([Voting § Anti-abuse](governance/voting.md#anti-abuse-rules)) is itself being ratified, so it doesn't apply to the ratification vote. Every founding member who has introduced themselves before the vote opens can vote.

## How to take part
1. **Join:** sign up at [unitedradicals.com](https://unitedradicals.com/#join) and [introduce yourself](https://github.com/unitedradicals/charter/discussions/1).
2. **Discuss:** in the ratification threads, propose concrete values and say why. Use 👍 on comments you agree with.
3. **Propose:** post ideas in Ideas, and back the ones you'd really put hours into.
4. **Talk:** weekly call on [Discord](https://unitedradicals.com/discord), **Thursdays at 18:00 Sofia time (16:00 UTC)**. Notes are posted in Discussions → General.

**Nobody is paid yet.** Revenue is shared once what we build earns money, as set out in the [economic model](economics/model.md).
